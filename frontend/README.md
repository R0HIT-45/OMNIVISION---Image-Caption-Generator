# OmniVision Frontend

React + TanStack Router + Tailwind CSS frontend for the OmniVision AI Image Caption Generator.

## Development

```sh
bun install
bun run dev
```

## Environment Variables

Set `VITE_OMNIVISION_API_URL` to point to the OmniVision backend API (e.g. `http://localhost:8000/api/v1`).
